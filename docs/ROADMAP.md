# Feuille de route

## v0.1 – base (cette version)
Caisse tactile, remises, article offert, coupons, paiements mixtes, compte client, avoirs, tickets, factures, clôture X/Z, statistiques, import depuis caisse.enregistreuse.fr.

- [ ] **Exports comptables** : CSV/FEC du journal des ventes
